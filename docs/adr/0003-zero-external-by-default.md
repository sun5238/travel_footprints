# 默认零外发：无账号、离线地图、无外部解析

全软件无账号、无登录；地图默认使用本地 .mbtiles 离线瓦片包（MapLibre GL JS），在线图源、店名候选/地理编码、云端或本地模型解析全部是显式开关且默认关闭。否决了“高德在线作默认图源”（高德 JS API 不支持离线，且在线瓦片会向图商暴露 IP、浏览视口与 key 关联画像）和“云同步”（用户明确要求数据不出设备）。本决策是代码中不可见的约束：任何引入外发网络请求的改动都必须先在 DESIGN.md 登记。

Status: accepted

Considered Options: 高德在线图源（底图数据最好但不可离线）、云同步（手机/电脑同一份数据但违背本地优先）、Tailscale 远程同步（列为后置可选，不进入 MVP）。
