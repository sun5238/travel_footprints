# 解析默认不用 LLM：规则 + 学习词典 + 标注库

文本导入不做 LLM 解析（含本地模型），采用“规则层 + 学习词典 + 校正页”管线：规则抓日期/交通词/动词/城市名，解析结果先展示后入库、绝不静默错认，未识别原文保留可全文搜索；每次人工校正写入标注库（原文 -> 标准 JSON）并回填学习词典。这条路线的准确率上限低于 LLM，但守住“数据不出设备”的底线，代价是最初几次导入需要人工校正确认。标注库为将来的本地模型（Ollama/Qwen）预留了直接可用的训练料，属于可逆决策，代码中保留开关位。

Status: accepted

Considered Options: 云端 LLM 解析（质量最高但游记内容外发，被拒）、本地模型起步（数据不出门但需下载模型、吃内存，后置）。
