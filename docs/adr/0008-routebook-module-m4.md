# M4 路书：独立规划模块（手动/引擎算路 + 单线模型 + 文件共享）

离线地图瓦片底座下加「路程规划（路书）」，覆盖自驾/骑行/徒步。经多轮设计评审（2026-10-03）定稿：

## 决策

- **独立模块**：`routebook`/`route_point`/`route_stop` 新表，暂不关联 trip/visit/点亮/完成流转（后置结账）。
- **输入不走文本导入管线**：手动输入 始终/途经点（命中本地 `City`/`place` 表取坐标）+ 地图选点补齐；坐标三态 `none | city | exact`。骑行地标大概率不在本地库 → 以地图选点为主，名称成为显示标签。
- **单线模型**：输入始终点（+途经点）→ 只生成一条线，用户在此基础上修改。**不设多候选线**。
- **引擎形态 C**：运行时进程内自建轻量路由（读预构建路网图 → 自管边权 → A*/双向 Dijkstra），引擎抽象层预留可切 Valhalla（Docker，后置）。**运行时无新依赖**；PBF→路网构建工具按"构建时可选在线"处理（Geofabrik/BBBike 免费无账号，国内网络可能慢/不通），引入 pyrosm/osmium 需单独确认。
- **偏好档位**：每模式 3 档预设（driving：balanced/scenic/fast；cycling：balanced/greenway/fast；walking：balanced/offroad/fast），存 `preset` 文本；「走风景多」= 路网邻域景点 POI 密度边加权。细粒权重 GUI 后置。
- **绿道数据不足的现实**：OSM 绿道覆盖弱，引擎 profile 只能偏好"数据里已有的绿道"；补法 = 途经点/线段打标（stop_type + 说明）+ 共享路书把绿道线传下去；社区补充路网包后置。
- **几何**：`geometry_source` = `engine | override`；引擎生成或用户覆盖手画（兜底），`geometry_json` 存 GeoJSON LineString。
- **里程**：引擎路网真值（可手动改并标 `mileage_manual`，重算不吞手动值）；爬升/海拔剖面后置。
- **导出双轨**：GPX `<rte>`（只唯一主线，给别的软件）+ 路书 zip（`manifest.json` + `route.geojson` + 打标/简介，本产品内共享）。zip 导入：新建一本（保留来源线索、可改名），同名不覆盖。
- **导航交接三选一**：一键深链 / 起终点导航 / 文本复制，在线动作、默认关、逐次确认。腾讯 routeplan 支持 `riding`（骑行深链走腾讯）；高德导航 URI 无骑行/途经支持 → 骑行高德文本兜底。
- **路书库**：独立入口/列表，按模式筛选，卡片显示模式/里程/始终点，按最近编辑排序；**不点亮城市**。
- **里程碑顺序**：M3 离线瓦片 + GPX 先落地 → M4 路书（瓦片是"与实路一致"的底子）。
